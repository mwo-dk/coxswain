| **Safer with hostile archives and files.** A 7z that unpacks to gigabytes is unpacked as it is read, no longer into memory, so it cannot take the app down; a zip whose files share their packed bytes (a few kilobytes that unpack to gigabytes) is not extracted whole, one file of it can still be copied out. Files and folders from a zip or a tar never come out writable by other users. An archive entry, a name index or a commit dated far in the future no longer ends the app, a VMDK whose extents add up past what a number holds shows the largest size instead of a wrong one, and a LaTeX file in Latin-1 is no longer mistaken for a part of another document. | [Archives](files/archives.md#limits) |
