| **The position index of a chess database: fixes.** A database whose file name is not in UTF-8 (a name in Latin-1, say) now gets its index instead of failing at the end of the build. An out-of-date index shows the number of games for a position fewer than 32 games reach, not 0. A build cut short by quitting or a crash no longer leaves up to gigabytes in the cache: *Disk use* removes it. A file replaced while its index was built is read whole next time, so its tree never counts the old file's games. | [Position index](previews/chess-positions.md#when-the-database-changes) |
