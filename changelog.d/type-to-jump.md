| **Typing letters jumps to a name in the desktop app, and a right-click opens the action menu.** Plain letters now jump to the first name that starts with them, as in a file explorer; the command line is on **Ctrl+K**. *Settings → Behaviour → Typing letters* chooses between jumping and Norton Commander's command line in either app (the terminal app keeps the command line by default; the first-run guide asks too). A right-click in the desktop app opens the action menu, and **Ctrl+click**, **Insert** or **Ctrl+right-click** mark; *Right-click* in Settings switches it back.
