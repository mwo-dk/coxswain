| **A file out of a large .tar.bz2 comes out at once.** The first time a `.tar.bz2` is opened, Coxswain keeps where a bzip2 block starts, one every 4 MB (about 11 KB for a 1.3 GB tar); a file taken out later is unpacked from the block before it, not from the start (the last file of a 1.3 GB `.tar.bz2`: 0.05 s instead of 19 s), from `bzip2` and `pbzip2` alike.
