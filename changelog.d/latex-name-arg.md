| **Security: a LaTeX file's name can no longer run a command.** The desktop app passed a `.tex` file's name to latexmk, tectonic and pdflatex as it was, so a name starting with `-` (such as `-pdflatex=…`) was read as an option, and latexmk runs that one through the shell, on a build that starts by itself when the cursor rests on a file. The document now goes as `./name`, a name with characters the shell would act on (such as `$` or a backquote) is built by the engine itself without latexmk, and `% !TEX root` is followed only to a file inside the project. | [LaTeX projects](previews/latex.md#what-coxswain-works-out) |
