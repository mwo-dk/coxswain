| **Chess games.** A PGN file (also `.pgn.gz` and `.pgn.zst`) opens as a table of its games, White, Black, ratings, result, date, event, ECO code and opening name, to filter by player, opening, result, years and rating and to sort by any column, filling while the file is read: a million games in a few seconds, in about 50 MB. **Enter** shows a game on a board in the theme's colours (or a green or brown tournament board), its moves beside it in figurines (♘f3) or your language's letters, variations in brackets, comments and annotation glyphs; **←** **→** step, **↓** **↑** go into a variation. EPD and FEN files show their positions. In the desktop app's preview pane and its own window (**Alt+K**), in the terminal app full screen (**F3** or **Alt+K**); *Open games* in the action menu and **F9**. Find finds games by player, event or opening (in a very big file the first 40,000 or so), and a hit opens that game. The search store reads every PGN file (`.pgn`, `.pgn.gz`, `.pgn.zst`) again once for this; nothing else is read again. | [Chess games](previews/chess.md) |
