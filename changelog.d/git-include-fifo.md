| **A repository that names a FIFO or a device for git to read no longer holds git for ever.** Its config, an `[include]` in it, the excludes, `HEAD`, the index or the top `.gitignore` as a named pipe (or `/dev/tty`) made the background git status, the filter check and the git config view wait until someone wrote to it. Each is now looked at before git runs, and where one is no plain file git does not run there; and those git runs are ended after two minutes whatever they wait on. | [Git](panels/git.md#why-is-there-no-git-line) |
