| **Permissions and dates soon after a save on FreeBSD change every file.** FreeBSD's UFS changes a file's entry by itself up to seconds after it is saved, so a run planned in that time left the file, or every file of its folder, as *Changed since the plan*. An entry still counts as the same when it is the same file at the same place with the permissions and date the plan saw; one chmodded or written since is still left. | [Permissions and dates](files/permissions-and-dates.md#what-is-left-out) |
