| **A graph in the git history.** Each commit in a history (**Ctrl+G**) has its place in a graph beside it: its lane, the lines to the commits it was made on and on top of, merges and the names of the branches and tags whose tip it is. **Alt+A**, or *All branches* next to the badge in the desktop app, lists every branch's commits, so the graph shows where they split off and were merged; **Alt+A** again goes back to this branch. SVG in the desktop app's *Details* view, box-drawing characters in the terminal app; worked out only as far down as the list is shown, so a long history opens as fast as before. | [The graph](panels/git-history.md#the-graph) | <!-- feature -->
