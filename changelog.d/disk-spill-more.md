| **Nothing a crash leaves looks whole, and every launch keeps its own leftovers.** A file copied out of an archive, a history or a version-control export, a file Sync folders brings over, an archive written anew and a saved settings file each come in under a hidden passing name and take their own only when whole, so a kill or a power cut never leaves a cut-off file under the real name; the next start removes the passing names. Each launch now has a name of its own (its process id and a random part), so launches in a Flatpak sandbox, which share a process id, no longer take each other's work for theirs. A folder on a network share that no longer answers no longer holds up the tidying at start, a folder whose name is not UTF-8 is tidied too, and a clean exit leaves no work folders behind. A run's drags keep at most 1 GB at once, and a recording of unknown length is transcribed ten minutes at a time instead of whole.
