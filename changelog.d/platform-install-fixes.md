| **Fixes for the BSD and illumos installs.** The install script's last line on OpenBSD, NetBSD and illumos linked to a page that does not exist; it now names the system's guide. On OpenBSD `man coxswain` no longer warns about an outdated `mandoc.db` after an install, and the rc.d script, when started without a user, now says in `/var/log/daemon` how to name one (rcctl only showed *failed*). On illumos the SMF service's message says to clear it after naming the user, and the guide says so too.
