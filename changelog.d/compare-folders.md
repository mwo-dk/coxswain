| **Compare folders, in both apps.** **Ctrl+F2** compares the left panel's folder with the right one's, every file under them, by size and date or byte by byte, and marks each entry in both panels as it is found: **+** only here, **>** newer, **<** older, **≠** different, **=** the same. **Ctrl+F2** again opens its menu: mark the differences for **F5**, or show the differences only. Archives, container images, snapshots and git histories are compared too, read-only. A link is compared as a link and never followed. Making one side like the other comes later.
