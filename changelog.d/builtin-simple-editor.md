| **A built-in editor in both apps.** **Shift+F4** edits a text file inside Coxswain: colours, undo, find and replace, go to line; saving keeps the file's encoding, line endings and permissions, and asks before writing over a file that changed on the disk meanwhile. In the terminal app **F4** opens it when no editor is set, instead of the first of `vi`, `nano` and the like that is installed. | [The built-in editor](commands/editor.md) |
