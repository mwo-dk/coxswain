| **Search looks inside container images, and an image opens at once the second time.** Find knows the files of a `docker save` or `podman save` tar's merged layers by name and by their text, never its blobs (an image over 256 MB once it has been opened). The merged tree and each gzip or zstd layer's places to unpack from are kept in the cache, so a file previewed or copied out comes from near where it is instead of from the start of its layer. **Read again, once:** every container image tar the search store already knows is listed again after the update, so the files of its merged layers are read (an image over 256 MB once it has been opened); no other file is read again, and nothing gets its vectors again but the files found inside images. | [Container images](files/container-images.md#in-search) | <!-- feature -->
