| **Stop a running copy, move, delete, extract or pack.** In the desktop app a progress bar with a Stop button (or Esc on it), in the terminal app Esc on the progress line: the file it was on is removed, what was done stays and Ctrl+Z undoes it, and the status line says how far it got (*Stopped: 120 of 400 copied*). A move to another disk now goes file by file, each original deleted only after its copy is checked, so every file is in one place at any time; an archive is written beside itself and left untouched when stopped, with a file left by a crash removed at the next start, and the pack dialog warns when space may be short. | [Stopping it](files/copy.md#stopping-it) | <!-- feature -->
