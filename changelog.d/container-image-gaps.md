| **Search looks into OCI image layout folders, and finds every name of a file in an image.** An OCI layout folder (`podman save --format oci-dir`, `skopeo copy … oci:`) is searched from its `index.json`, as an image tar is. A file under several names in an image (a hard link, a link to a file) is found under each name by its text, not only the first. An image tar or compressed tar over 256 MB is searched at the next scan after you opened it, though the file did not change; an image on a disk not plugged in during the update's redo is listed once the disk is back. **Read again, once:** the OCI layout folders the search store already knows are listed again with the image tars, so the files of their layers are read; nothing else is read again. | [Container images](files/container-images.md#in-search) | <!-- feature -->
