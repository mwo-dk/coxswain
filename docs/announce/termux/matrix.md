# Matrix: the Termux room

Find the room's current address on <https://termux.dev> (*Community*) before posting; it was
`#termux:matrix.org`, bridged to Termux's other chats, but check it on the day.

Short, as one message:

> Coxswain, a two-panel Norton Commander style file manager (Rust, MIT), is now in Termux:
> `pkg install coxswain`. After `termux-setup-storage`, Alt+F1 lists your phone's folders;
> Enter opens files with `termux-open`; with Termux:API it uses Android's clipboard and waits
> on battery. Terminal app only. Guide:
> https://github.com/mwo-dk/coxswain/blob/master/docs/reference/termux.md
