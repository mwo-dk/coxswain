| **Saving in the editor and in Compare files keeps the file whole and as it was.** A full disk or quota no longer leaves half a file: the save is refused and the file left as it was. The new text is private to you until it has the file's permissions and group; a read-only file is refused rather than replaced, and another user's file, or one with an ACL or extended attributes, is written in place so it keeps them. Replace all no longer cuts the wrong text after ẞ, the Kelvin sign or İ. In Compare files, **N** and **P** in two binary files look on a thread (**Esc** stops it), hex rows put the right side under the left below 110 columns instead of cutting it off, and Compare folders no longer says the folders are the same when a file stands against a folder. | [Editor](commands/editor.md#saving-what-is-kept) · [Compare files](files/compare-files.md#documents-pictures-and-other-files) · [Compare folders](files/compare-folders.md#how-to-use-it) |
