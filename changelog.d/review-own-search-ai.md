| **Search inside files is safer with files made to harm it, and keeps what it read of a disk that is away.** The search helper no longer drops the text of the files on an unplugged disk or share when a reader asks for them again: they keep their text and are read once the disk is back. A Word document of runs never closed, or a PDF of forms sharing their resources, is read for seconds at most instead of for hours; a text file of blank space or zero bytes (a sparse file of a terabyte) is read no further than 256 MB, and a longer log gets its passages from its first gigabyte; a line of one endless word no longer takes gigabytes while its passages are made; a tar of very long names keeps no list of gigabytes in the cache. A container runtime that starts late (Tika, calibre) no longer makes its files be read and given vectors again. Find this position leaves out a PGN file `text_exclude` names, and a file stopped part way is read again. Ask makes an earlier answer as inert as a source in the next prompt, an embedding server's error page is shown in one short line, and a model download stops when it is longer than the file expected. | [Documents it reads](search/documents.md#settings-and-configtoml) · [Search by meaning](search/meaning.md#how-it-works) |
