| **Other programs can use Coxswain to choose files and folders.** `coxswain --pick=FILE` (with `--folder`, `--multiple`, `--filter`, `--start`, `--title`) opens the terminal app in pick mode: Enter chooses, Esc cancels, the paths go to the file or standard output, and the exit status says whether anything was chosen. A file chosen inside an archive is unpacked to the cache first. The desktop app and `--save` follow. | [Pick mode](reference/pick-mode.md) | <!-- feature -->
